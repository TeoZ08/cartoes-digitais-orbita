COMPARTILHAMENTO

Como o cliente abre o cartão?

Uma tag NFC contém o link do perfil do vendedor. O mesmo endereço pode ser compartilhado por QR Code ou mensagem.

Por aproximação NFC

O vendedor aproxima a tag de um celular compatível. O visitante recebe uma notificação para abrir o perfil.

Escaneando um QR Code

A câmera do celular identifica o código e abre o cartão digital.

Por link

O vendedor envia o endereço por WhatsApp ou qualquer outro canal.
