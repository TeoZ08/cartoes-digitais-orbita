COMPARTILHAMENTO

Como o cliente
abre o cartão digital.

Uma tag NFC é uma pequena peça com chip, como um adesivo ou chaveiro. Ela guarda o endereço da página do vendedor. Ao aproximar um celular compatível, aparece um aviso para abrir o perfil.

01NFC

O vendedor apresenta a tag; um celular compatível mostra o link da página para o cliente abrir.

02QR Code

O cliente aponta a câmera para o QR Code e abre a mesma página.

03Link

O vendedor pode enviar o link por mensagem, sem precisar da tag física.
